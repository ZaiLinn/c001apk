# 动态备份与离线阅读

在动态详情的右上角菜单，或列表中动态的“更多”菜单里选择“备份”。第一次使用时选择一个可读写的文件夹，应用会保存目录授权并自动继续刚才的备份。

备份会重新读取完整动态，保留文章段落，逐页读取主回复及楼中楼，再下载正文、作者头像、回复和楼中楼中的图片。备份请求不使用应用内的黑名单过滤，也不会把热门评论或列表摘要当成完整内容。

同一条动态再次备份时，可以选择“取消”“均保留”或“替换”。替换会先保存好新的一对文件，成功后再删除这条动态的旧版本；失败或取消时保留旧备份。

“我的 → 我的备份”和“设置 → 我的备份”可以打开备份列表、重新选择目录或手动同步。列表按动态编号去重，打开最近保存的一份。“均保留”产生的其他版本仍在文件夹内。删除备份需要确认，会删除这条动态的各版本 JSON 和 ZIP；本地收藏不会跟着删除。

换设备或清除应用数据后，重新选择原来的备份目录，列表会从文件重建。打开列表里的条目始终读取本地文件，不会先尝试在线详情。正文、文章图片、回复、楼中楼和大图均可离线查看；“打开在线动态”是单独的菜单操作。

## 文件格式

每份备份由同名的两个文件组成：

```text
feed_123456.json
feed_123456.zip
feed_123456_时间戳_随机后缀.json
feed_123456_时间戳_随机后缀.zip
```

JSON 使用迁移说明中的 `{feed, replies}` 结构，另有 `formatVersion`、`savedAt`、`images` 和 `warnings`。新文件使用版本 2，并记录 `imageQuality`（`None` / `Preview` / `Original`）、`includesReplies` 与 `listFingerprint`；图片条目的 `savedUrl` 记录实际下载的地址。旧文件缺少这些字段时按原图、包含回复处理。`feed` 保留 API 的 `data` 包装；`images` 记录原始 HTTPS 地址、ZIP 内文件名、大小和 SHA-256。JSON 中保留原始图片地址，离线阅读时才在内存中改为本地地址。

ZIP 图片使用 STORED 模式，不再次压缩已压缩的图片。离线加载验证 CRC 和 SHA-256，且不会将 ZIP 内的路径直接用作本地文件路径。

可导入迁移说明里的 `{feed, replies}` JSON，以及更早的裸 `{data: ...}` JSON。旧 ZIP 没有图片映射时，按说明中的图片收集顺序尝试恢复，并在离线页提示；没有 ZIP 时仍可阅读文字与回复。

## 缺失与限制

只有服务器实际允许读取的内容才能备份。获取完整动态失败时不会用列表摘要替代；回复或图片读取失败时保留已经读取的内容，并在列表及详情中标明缺失，不提示为完整成功。

为避免重复分页、异常文件和无限占用存储，回复及每个楼中楼最多读取 1000 页，重复页面会停止并标明；单张图片最多 64 MiB，一份备份的图片合计最多 512 MiB、最多 20000 张，JSON 最多 32 MiB。图片缺失时不影响已保存的正文和回复。

独立视频及分离的实况视频不在本功能的图片备份范围；图片文件本身嵌入的视频会随原文件保留。离线页不会为了播放实况而请求服务器。

## 批量备份与收藏同步

“我的收藏”菜单和“我的备份”中可打开“同步云端收藏”，登录后选择收藏夹开始单向备份；搜索页也可批量备份全部本地收藏。默认选择**文字和原图、包含回复、允许移动网络下载图片**，可以改成仅文字、缩略图、不包含回复或仅 WiFi 下载图片。单条菜单备份仍使用原图和全部回复。

缩略图档位保存酷安图片的预览版本；其他图片超过 2 MiB 时跳过并记录缺失。头像保存缩略图。仅文字档位使用空图片 ZIP；离线页会区分主动选择“未包含回复”和回复读取不全。

同步只读取云端，不改变收藏夹。列表指纹相同且已有档位满足要求时跳过；文字变化、图片或回复档位升级时重新备份，也可选择“全部重新备份”。云端取消收藏只标注来源，不删除文件；某收藏夹读取失败时不会据此判断取消收藏。更新时按已有备份和本次选择的较高图片档位、完整回复选项保存并替换，避免降低主版本的完整度。首次同步遇到档位足够但缺少列表指纹的手动备份，只补记索引指纹，不重新请求详情或新增文件。

任务逐条执行，请求之间等待 3–5 秒，每 50 条额外休息 30 秒，一次最多处理 500 条，剩余任务可继续。进度显示完成数、失败数和预计时间，支持暂停、取消、重试失败项；进程结束后重新进入同步页可续传。遇到验证码会暂停，需手动验证后继续。同步仅在应用进程运行时执行。

“设置 → 备份与收藏”可开启收藏时自动备份，默认关闭。开启后，加入云端收藏夹或本地收藏会加入相同队列；用户暂停或验证码暂停期间只入队，需手动继续；尚未选择目录时提示选择目录，不阻塞收藏。

## 搜索与在线回退

本地收藏、我的收藏和我的备份页面的搜索入口共用本地搜索。支持多词同时匹配、范围与收藏夹筛选、相关度及时间排序。未备份的本地收藏只能搜索已保存的短预览，会标注“未备份全文”。

搜索结果优先打开在线动态。网络错误或明确的删除、权限业务错误会改为显示已有本地备份，并提供备份时间、复制全文和重试在线；验证码和账号验证错误不会触发回退。长按结果也可直接打开本地备份。

搜索索引保存在应用私有的 SQLite 数据库中；备份文件才是正文和图片的数据源。日常扫描只读取新增或变化的 JSON，“重建索引”可重新解析所有文件。更换设备或清除应用数据后选择目录即可恢复正文索引；云端收藏夹来源关系需重新同步云端收藏恢复。

## 导出

“我的备份 → 导出”或搜索页“导出当前结果”可选择全部、本地收藏、当前账号的云端收藏、指定收藏夹或当前搜索结果，按发布时间排列，可选是否包含已备份的回复。

- TXT：UTF-8，包含作者、时间、链接、来源、正文及可选回复。
- HTML：含目录、段落与深色模式的文字文件；正文经过清洗。
- HTML 含图片：ZIP 内含 `index.html` 与 `images/`，使用备份中已经校验的图片，不重新下载，也不嵌入 base64。

通过系统文件选择器保存，显示进度并可取消；取消或失败会尝试删除未完成的输出。开始前估算所需空间，每次最多导出 20000 条。HTML 超过 64 MiB 时分卷并打包为 ZIP，文字 HTML 模式也会提示改存 ZIP。缺失的动态或图片会在输出中说明。TXT 和文字 HTML 仅解析 JSON，不复制或解压图片 ZIP。导出和本地阅读不发网络请求。
