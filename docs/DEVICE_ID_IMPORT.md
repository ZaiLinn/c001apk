# 导入官方设备标识（数盟 ID）

浏览动态或评论时反复要求人机验证，可以试试从官方酷安导入数盟 ID（SZLM ID）。入口：**设置 → 协议与设备 → 导入官方设备标识**。

这是临时方案：有效期以及是否要求验证都由酷安服务端决定，导入后仍可能遇到验证。

## 1. 打开官方酷安的「检查日志和测试」页

先安装官方酷安（`com.coolapk.market`）并正常打开一次，不需要登录，也不需要 root。

在导入页点击 **酷安 OAID 界面**，会直接打开官方酷安的「检查日志和测试」页。也可以用官方酷安打开这个链接：

```
coolmarket://www.coolapk.com/native/testSettings
```

未安装官方酷安时会提示先安装；已安装但打不开时，请确认官方酷安已启用并更新到最新版本。入口按官方 16.6.4 整理，其他版本可能变化。

## 2. 在同一页点「复制 OAID」5 次

向下滚动找到 **复制 OAID**，在同一个页面里慢慢累计点击 **5 次**。前 4 次只复制 OAID 或提示没有 OAID，第 5 次才会复制包含多个字段的完整文本：

```text
设备ID: …
ShuzlmID: …
AndroidID: …
UUID: …
```

按钮虽然叫「复制 OAID」，这里使用的是其中的 **ShuzlmID（数盟 ID）**。整段复制即可，不用自己挑出字段。

## 3. 回到 c001apk 粘贴并保存

回到导入页点击 **粘贴并识别**（或长按输入框手动粘贴）。显示「已识别数盟 ID」后点击 **保存并应用**，回到内容页刷新即可。

c001apk 只保存识别出的数盟 ID，用它替换请求设备编码的第一段；其余复制字段会被忽略，机型、系统版本等设备参数和登录状态都保持不变。只有点击「粘贴并识别」时才会读取剪贴板。

## 常见情况

- **提示未识别到 ShuzlmID**：可能只复制到了 OAID。重新进入官方页面，在同一页累计点击 5 次后再粘贴完整文本。
- **数盟 ID 为空或格式不正确**：打开官方酷安稍等片刻后重新复制，不要用 AndroidID、UUID 或随机值代替。
- **保存后仍出现验证**：标识可能已失效，也可能是账号、网络或接口本身的限制。可以重新复制导入；仍要求验证时按正常流程完成验证。
- **想换回原来的设备标识**：在导入页点击「清除」，会改用新生成的随机设备标识。

数盟 ID 只保存在本机、用于发给酷安的请求。不要把复制的整段文本、真实 ID 或含标识的截图发到 Issue、群聊或公开仓库，也不要使用别人的标识。
